### About This Fork

**React95 Refresh** (`react95-refresh`) is a modernized fork of the original [React95](https://github.com/arturbien/React95) library created by Artur Bień, featuring a complete overhaul of all libraries and tooling:

- **React 19 + React Compiler** (`babel-plugin-react-compiler`)
- **styled-components v6** with transient props and zero DOM warnings
- **TypeScript 7** with dual ESM/CJS exports
- **Rolldown (`tsdown`)**, **Vite 8**, **Vitest 5**, **Storybook 10**, and **Biome**

### Getting Started

Check out our [getting started](?path=/docs/docs-getting-started--docs) docs!

### Motivation

Create modern mobile/web applications with the retro and old school Windows 95 style. Our goal is not to exactly recreate Windows95 components, but to provide a solid, modern component library for current React scenarios.
